# wp-product-compare — Comparador de productos

**Nombre comercial propuesto:** **Product Compare VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 124/131 — Comparador de productos  
**Estado:** Carpeta creada para planificar; sin PHP ejecutable, instalación ni ZIP.  
**Monetización:** Gratuito por defecto; APIs externas facturadas al usuario cuando proceda.

## Para qué serviría

Comparar características de varios productos en una vista común.

## Dirección técnica inicial (por evaluar)

Modelo de atributos homogéneo, rendimiento y diseño desacoplado.

## Referentes del mercado (solo investigación)

[YITH WooCommerce Compare](https://wordpress.org/plugins/yith-woocommerce-compare/)

**Instalaciones de referencia:** 100 mil+ (observación del catálogo al 20/11/2026; no son ventas verificadas).

**Relación con otras categorías:** Se complementa con búsqueda de productos (80) y variantes (67).

**Dificultad estimada:** 3/5. Estimación de ingeniería del inventario, no un cálculo de costo ni tiempo.

## Antes de implementar

Delimitar la V1, resolver solapamientos con las demás carpetas, definir permisos y datos, verificar compatibilidad WordPress/PHP, licencias y dependencias, y decidir el modelo comercial. Mantener versión, distribución y contratos propios; la biblioteca `shared/` es opcional. No afirmar que existe un plugin instalable por tener esta ficha.
