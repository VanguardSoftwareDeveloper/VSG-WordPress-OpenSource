# wp-captcha — CAPTCHA y defensa antibots

**Nombre comercial propuesto:** **CAPTCHA VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 116/131 — CAPTCHA y defensa antibots

Proteger formularios, registros y accesos de actividad automatizada.
