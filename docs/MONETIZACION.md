# Política económica de plugins WordPress

**Decisión del propietario (22/11/2026): regalar el software y el mantenimiento voluntario; cobrar únicamente cuando Vanguard tenga que pagar de su propio bolsillo una API, infraestructura o un servicio externo para ofrecer funcionalidad.**

El tiempo de análisis, diseño, programación, documentación, desarrollo de nuevas funciones, mantenimiento y soporte voluntario **NO constituye una razón para cobrar**. No volver a proponer precio por duración, riesgo comercial, dificultad, mercado, competencia, mantenimiento o valor percibido si no hay gasto externo de proveedor facturado a Vanguard.

## Modelos permitidos

- **Gratuito local (opción por defecto):** hosting, SQL, PHP, WordPress y almacenamiento del usuario. El plugin y sus actualizaciones se ofrecen sin cobrar por esas tareas cuando se desarrollen.
- **Gratuito con proveedor del cliente (BYOK):** si la funcionalidad depende de API, transacciones, envío, IA, mapas, mensajes, archivos o procesamiento externo, la cuenta, claves, cuota y factura deben pertenecer directamente al cliente cuando el proveedor lo admita; no hay cobro de licencia por el plugin.
- **Servicio de pago opcional:** cuando Vanguard decida alojar/financiar el consumo necesario para prestar una funcionalidad adicional y se confirme la factura concreta a su nombre, puede cobrar por el servicio administrado con costos y límites transparentes. Mantener gratuito el plugin base y ofrecer opción de conexión directa al cliente donde exista.
- **Sin producto de pago aprobado:** a la fecha, ninguna categoría del catálogo acredita una obligación financiera del fabricante. Las cifras 55 gratis/76 comercial fueron una evaluación por costos de desarrollo y **quedaron revocadas** por el nuevo criterio.

## Controles para evitar costos sorpresa

1. Ninguna API key o cuenta de pago de Vanguard debe servir por defecto a usuarios de plugins gratuitos.
2. Configurar credenciales del cliente del lado servidor y explicar claramente costos y condiciones del proveedor antes de habilitar operaciones.
3. Si un proveedor no permite que el cliente sea el pagador, investigar integración alternativa y comprobar gasto obligatorio antes de plantear servicio de pago.
4. Si se ofrece pago administrado, fijar consumo, límites, reporte de uso, facturación y tarifa explícita. Evitar subsidios o gasto abierto a nombre de Vanguard.
5. Verificar términos y tarifas oficiales actuales por país, servicio y cuenta; esta clasificación no garantiza que un tercero sea gratis ni que acepte BYOK.
