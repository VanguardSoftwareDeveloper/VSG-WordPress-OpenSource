# wp-user-switching — Cambio controlado de usuario

**Nombre comercial propuesto:** **Session Switch VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 113/131 — Cambio controlado de usuario  
**Estado:** Carpeta creada para planificar; sin PHP ejecutable, instalación ni ZIP.  
**Monetización:** Gratuito por defecto; APIs externas facturadas al usuario cuando proceda.

## Para qué serviría

Permitir a administradores autorizados inspeccionar una sesión como otro usuario.

## Dirección técnica inicial (por evaluar)

Registro de suplantación, expiración, límites de rol y retorno seguro.
