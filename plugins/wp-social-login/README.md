# wp-social-login — Acceso mediante cuentas externas

**Nombre comercial propuesto:** **Social Sign-in VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 114/131 — Acceso mediante cuentas externas  
**Estado:** Carpeta creada para planificar; sin PHP ejecutable, instalación ni ZIP.  
**Monetización:** Gratuito por defecto; APIs externas facturadas al usuario cuando proceda.

## Para qué serviría

Registrarse o iniciar sesión con proveedores externos como Google.

## Dirección técnica inicial (por evaluar)

Flujos OAuth/OIDC verificados, vinculación segura de cuentas y mínimos datos.

## Referentes del mercado (solo investigación)

[Nextend Social Login](https://wordpress.org/plugins/nextend-facebook-connect/)

**Instalaciones de referencia:** 200 mil+ (observación del catálogo al 20/11/2026; no son ventas verificadas).

**Relación con otras categorías:** Complementa registro y autenticación de usuarios (43).

**Dificultad estimada:** 4/5. Estimación de ingeniería del inventario, no un cálculo de costo ni tiempo.

## Antes de implementar

Delimitar la V1, resolver solapamientos con las demás carpetas, definir permisos y datos, verificar compatibilidad WordPress/PHP, licencias y dependencias, y decidir el modelo comercial. Mantener versión, distribución y contratos propios; la biblioteca `shared/` es opcional. No afirmar que existe un plugin instalable por tener esta ficha.
