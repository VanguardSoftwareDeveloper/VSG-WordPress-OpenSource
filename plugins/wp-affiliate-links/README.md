# wp-affiliate-links — Gestor de enlaces de afiliación

**Nombre comercial propuesto:** **Affiliate Links VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 118/131 — Gestor de enlaces de afiliación  
**Estado:** Carpeta creada para planificar; sin PHP ejecutable, instalación ni ZIP.  
**Monetización:** Gratuito por defecto; APIs externas facturadas al usuario cuando proceda.

## Para qué serviría

Administrar enlaces rastreables, redirecciones y campañas de afiliación.
