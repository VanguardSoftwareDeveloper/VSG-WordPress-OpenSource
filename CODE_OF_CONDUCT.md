# Community code of conduct

This project aims to provide accessible, free-by-default WordPress software and a collaborative space for contributors of all backgrounds.

We expect participants to communicate respectfully, give specific and constructive technical feedback, credit sources and contributors, and distinguish evidence from hypotheses. Harassment, threats, discrimination, personal attacks, spam, doxxing, intentional misrepresentation of contribution metrics and disclosure of private customer data are not acceptable.

Project maintainers may moderate discussions, edit or remove abusive material, reject contributions and restrict participation where needed to protect the community. Moderation decisions will be based on conduct, not disagreement with a technical proposal.

For a conduct issue involving private details, **do not post personal information in a public issue**. Contact the maintainers using an appropriate verified private channel once the public repository provides one. A confidential reporting channel must be configured before public community launch.

Security vulnerability reports follow [SECURITY.md](SECURITY.md), not public discussions. These guidelines apply to issues, pull requests, discussions and project-managed community spaces.
