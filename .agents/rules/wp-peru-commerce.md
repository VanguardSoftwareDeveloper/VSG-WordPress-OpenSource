# PeruCommerce VSG

Before reading or editing files under `plugins/wp-peru-commerce/`, read `plugins/wp-peru-commerce/AGENTS.md`. Inside that folder it prevails over the root `AGENTS.md` for domain, security and release contracts.

This rule only routes context. It adds no permissions.
