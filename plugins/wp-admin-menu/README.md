# wp-admin-menu — Personalización de menú administrativo

**Nombre comercial propuesto:** **Admin Menu VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 106/131 — Personalización de menú administrativo  
**Estado:** Carpeta creada para planificar; sin PHP ejecutable, instalación ni ZIP.  
**Monetización:** Gratuito por defecto; APIs externas facturadas al usuario cuando proceda.

## Para qué serviría

Reordenar y organizar menús de administración por usuario y rol.

## Dirección técnica inicial (por evaluar)

Reglas claras y reversibles, sin confundir ocultar menús con permisos reales.
