# wp-media-offload — Almacenamiento multimedia externo

**Nombre comercial propuesto:** **Media Offload VSG**. Nombre de presentación; los identificadores técnicos permanecen sin cambios.

**Categoría:** 109/131 — Almacenamiento multimedia externo  
**Estado:** Carpeta creada para planificar; sin PHP ejecutable, instalación ni ZIP.  
**Monetización:** Gratuito por defecto; APIs externas facturadas al usuario cuando proceda.

## Para qué serviría

Guardar adjuntos en almacenes de objetos como S3 y servirlos mediante URLs adecuadas.

## Dirección técnica inicial (por evaluar)

Conectores sustituibles, integridad, eliminación segura y migración reversible.
